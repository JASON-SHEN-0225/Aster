Aster · 星流 3.0.0 更新日志
发布日期：2026-11-27
适用平台：Windows 10/11 桌面端、Android 手机端（APK / 手机网页）

本次 3.0.0 的重点，是让手机真正成为“随手可用的一端”，同时把传输控制权交还给用户。

一、手机 APK 接入系统共享
- 在微信、文件管理器、相册等应用里选择“分享”或“用其他应用打开”，现在可以选择 Aster。
- 支持单个/多个文件，也支持分享纯文本。
- 分享内容会先暂存；连接电脑成功后自动加入手机端“待发送”队列，确认后再发送，不会偷偷上传。
- 未连接时，手机连接页会显示“已收到 N 个共享文件，连接后自动加入待发送列表”。

二、手机端设备命名
- APK 默认读取系统设备名；读不到时使用“厂商 + 型号”，再读不到就生成一次随机编号（例如“手机-3721”）。
- 浏览器网页端默认显示“网页端设备”。
- 手机设置里新增“本机名称”，可随时改名；电脑端设备卡片会区分“Android 手机 / 网页端设备”并同步显示新名字。

三、桌面端深浅色一键切换
- 浅色/深色滑块移到所有页面右上角，和网页端一样一键切换，不再需要进设置。
- 设置页里原来的主题下拉已移除，避免两个入口不同步。

四、APK 启动不再自动扫码
- 打开 App 后停留在“扫码 / 连接”主界面，预填上次地址，但不会自动扫码、也不会自动连接。
- 扫码仍然由“扫码”按钮触发，连接由“连接”按钮触发。

五、连接页动态星流图标
- 手机连接页顶部的星标换成自绘动态图标：旋转椭圆轨道、轨道小点、呼吸光晕、渐变八角星，和电脑端首页的星轨动画同一套视觉。

六、手机退后台继续传输 + 通知中心实时进度
- 手机上传时启动前台传输服务，持有唤醒锁，退到后台后传输继续。
- 通知中心实时显示文件名、百分比和速度，支持在通知栏直接“取消”。
- 手机下载也统一走前台服务，通知里补充了实时速度。
- 真机回归时修复了“传输中从桌面图标回到 App 会跳回连接页并中断上传”的问题。
- 建议在系统设置里允许 Aster 后台运行，部分厂商的省电策略仍可能限制后台网络。

七、任务取消（重做）
- 电脑端传输页：每个进行中的任务，进度条下方直接显示“取消”按钮；页面顶部新增“取消全部任务”。
- 手机网页传输页：每个任务进度条旁显示“取消”，传输区顶部新增“取消全部”。
- 覆盖发送、接收、等待对方确认；取消后会删除临时分片并标记“已取消”。
- 修复了 2.0 中取消按钮在手机传输（网页通道）和接收任务上不显示、点击后不生效的问题。

八、检查更新
- 电脑端“设置 → 关于与更新”新增“检查更新”按钮；每次启动会在后台自动检查。
- 手机 APK 每次启动自动检查；手机网页设置里也新增版本与更新入口。
- 发现新版本时提示版本号，并提供下载按钮，不强制更新、不自动安装。
- 更新信息优先读取官网 version.json，读取失败时回退 GitHub Releases。

其他改进
- 网页端服务端新增设备类型（APK / 网页）字段，电脑端历史记录会区分 “APK / 网页 / 电脑”。
- 版本号统一升级为 3.0.0（Android versionCode 30000）。
- 传输协议保持兼容，2.0 与 3.0 的电脑端仍可互传；旧版 APK 也可以继续连接新版电脑网页。

升级说明
- 桌面端：运行 Aster-Setup-3.0.0.exe 覆盖安装，配置、历史和接收目录都会保留；也可以直接替换免安装的 Aster.exe。
- 手机端：安装 Aster-3.0.0-release.apk，使用同一签名，可直接覆盖安装 2.0 正式版；如果之前装的是 debug 版，需要先卸载再装。
- 首次使用共享/后台传输时，系统会请求通知权限；拒绝后传输仍可进行，但通知中心不会显示进度。

已知限制
- 手机端后台传输依赖 WebView 与系统前台服务，极端省电模式下仍可能被暂停。
- HTTPS 使用自签名证书，首次连接需要在手机上手动确认。
- 手机网页和 APK 都需要电脑端 Aster 正在运行。
- 手机网页上传大文件时不做整文件 SHA-256（只做长度校验）；电脑之间传输仍带 SHA-256。

感谢使用 Aster · 星流。
